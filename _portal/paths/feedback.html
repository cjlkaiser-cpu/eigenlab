Retroalimentacion

Bucles que se auto-regulan. La salida afecta la entrada, creando estabilidad o amplificacion explosiva.

La idea central

Un sistema con retroalimentacion usa su propia salida para modificar su entrada. Negativa: estabiliza (termostato, homeostasis). Positiva: amplifica (avalanchas, panicos).

Los bucles de retroalimentacion estan en todas partes: ecosistemas, reacciones quimicas, genes, economia. Entender feedback es entender como los sistemas se auto-organizan, se estabilizan o colapsan.

1

Ecosistema (Lotka-Volterra)

Biology Visual Lab

Depredadores y presas en un baile eterno. Muchas presas → mas depredadores → menos presas → menos depredadores → mas presas... Un bucle de feedback negativo que genera oscilaciones perpetuas.

Patron clave: El sistema nunca alcanza equilibrio estatico — oscila alrededor de el. El feedback negativo no elimina variacion, la canaliza en ciclos regulares.

2

Principio de Le Chatelier

Chemistry Visual Lab

Un equilibrio quimico perturbado se desplaza para contrarrestar el cambio. Agregas reactivo → el sistema consume reactivo. Subes temperatura → el sistema favorece la reaccion endotermica. Feedback negativo puro.

Conexion con ecosistemas: Ambos sistemas "resisten" cambios. Le Chatelier es el Lotka-Volterra de las moleculas — un equilibrio dinamico que se auto-corrige.

3

Regulacion Genica

Biochem Visual Lab

Los genes se regulan a si mismos. El operon lac: la lactosa activa genes que la digieren; sin lactosa, los genes se apagan. Feedback negativo a nivel molecular — la celula solo gasta energia cuando es necesario.

Conexion con Le Chatelier: La regulacion genica es equilibrio quimico con logica. Represores y activadores son las "fuerzas" que desplazan el equilibrio de expresion genica.

4

Oscilador Forzado

Physics Visual Lab

Un pendulo con fuerza periodica externa. Si la frecuencia de forzamiento coincide con la natural: resonancia — la amplitud explota. El puente Tacoma Narrows colapso por resonancia con el viento.

Conexion con regulacion: La resonancia es feedback positivo. Cada empujon en el momento justo amplifica el anterior. Sin amortiguamiento, el sistema se destruye.

5

Potencial de Accion

Biology Visual Lab

La neurona dispara con ambos tipos de feedback. Fase ascendente: canales de Na+ se abren, entra Na+, mas canales se abren (positivo). Fase descendente: K+ sale, repolariza, canales se cierran (negativo). El pulso se propaga.

Sintesis final: Los sistemas biologicos usan feedback positivo para respuestas rapidas (disparo neuronal, coagulacion) y negativo para estabilidad (homeostasis). La vida es un equilibrio de ambos.
